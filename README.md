# 生图工作台

把 NovelAI 官网的生图页接到你自己的账号上。浏览器只跟本机程序说话；你的持久 Token 留在服务器上，不会写进网页。

别人拿到这个仓库后，**不用再写一套后端**。把自己的 Token 配进来，再放上自己保存的官网页面文件，就可以用工作台出图。出图、流式出图、放大、Vibe、增强、标签补全会原样转到你配置的图像服务（默认是 NovelAI）。密钥库和客户端设置存在本机数据库里。

账号、支付、训练模块没有实现。点了那些按钮不会有账户操作。

## 你需要自己准备

1. 一个 NovelAI 持久 Token（账户设置里生成）。只放在 `.env` 的 `NAI_TOKEN`。
2. 一个至少 16 位的本机访问口令 `ACCESS_KEY`。这不是 Token。打开页面后在本机口令框里输入，它只留在当前标签页。
3. 官网生图页的静态文件，目录里要有 `image.html` 以及它引用的 `/_next`、`/js` 等资源。放到 `mirror/nai-app/`。这些文件不在本仓库里，也不要提交。

如果你已经有一个兼容 NovelAI 图像接口的服务，把 `NAI_IMAGE_HOST` 指过去，`NAI_TOKEN` 填那个服务认的凭据。本程序仍然负责工作台要的 `/user/*` 启动接口。`http://` 只允许指向本机。

## 运行

```bash
cp .env.example .env
# 编辑 ACCESS_KEY 和 NAI_TOKEN
cargo run --release
```

浏览器打开 `http://127.0.0.1:8787/image`。

默认只监听 `127.0.0.1`。要给局域网用，必须同时改 `BIND` 并设置 `ALLOW_LAN=1`。口令知道的人就能花你的 Token，不要直接暴露到公网。

页面上的 Anlas 数字：能读到你账号的订阅时，用订阅里的余额；读不到时用一个仅供界面解锁的占位值。真正扣费以图像服务的返回为准。

## 不会出现在这个仓库里的东西

成员身份、聊天账号、服务器地址、真实 Token、官网前端构建产物、提示词日志。请求日志只记路径和状态码。
